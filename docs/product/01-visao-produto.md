# 01 — Visão do Produto

## Objetivo
Criar um SaaS simples para profissionais autônomos e pequenas empresas criarem, gerenciarem e compartilharem propostas comerciais e orçamentos.

## Problema
O produto substitui orçamentos enviados por WhatsApp em texto, documentos manuais, PDFs criados individualmente e planilhas, permitindo acompanhar visualização e decisão do cliente.

## Fluxo principal
1. Usuário cria conta.
2. Usuário cadastra cliente.
3. Usuário cria proposta.
4. Usuário adiciona itens e valores.
5. Usuário salva como rascunho.
6. Usuário publica a proposta.
7. Sistema gera link público único.
8. Cliente acessa sem login.
9. Cliente aprova ou recusa.
10. Usuário acompanha o status.

## Princípio do MVP
O MVP deve resolver apenas quatro problemas:
- Criar uma proposta.
- Compartilhar a proposta.
- Permitir visualização pelo cliente.
- Registrar aprovação ou recusa.

Não transformar o MVP em ERP, CRM ou sistema financeiro completo.
